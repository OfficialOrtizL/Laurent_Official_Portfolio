# Laurent Ortiz — Cybersecurity Portfolio

A static, responsive portfolio with project filters and expandable case studies. No dependencies or build step required.

## Publish with GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your actual GitHub username).
2. Upload `index.html`, the `assets` folder, and this README to the repository root. Upload the files, not the ZIP itself or its enclosing folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. When deployment completes, open `https://YOUR-USERNAME.github.io/`.

An existing repository also works; its address will generally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Customize

Open `index.html` in a text editor. CSS is inside the `<style>` element. Project case studies are in the `projects` array near the bottom. Biography, skills, and experience are in the HTML.

Review all personal details and case studies before publishing. The updated version includes your resume PDF, professional email, and Strategic Network Response assignment. Add your GitHub profile when ready. Preserve the assets folder structure so PDF links work.

## Local preview

Open `index.html` directly in a browser. Project filtering and case-study dialogs require JavaScript. There is no backend or contact form.

## Project collections

The project area has separate Cybersecurity & Technology and Criminal Justice — SLCC tabs. All four SLCC PDFs are exclusively in the SLCC tab. The project array in index.html controls summaries, categories, collection membership, and PDF links.
